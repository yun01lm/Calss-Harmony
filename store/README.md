## 3. 应用介绍（限 8000 字，纯文本，不支持 HTML）

```
简课表是一款把课表装进手机的本地应用：打开就是周课表，不联网、不申请任何权限，数据只存在你自己的设备里。

【三种导入方式】
· 教务系统导出的 .xls：很多学校导出的其实是网页表格，直接选文件即可，课程名、教师、教室、周次、连堂节次都会自动拆好
· 课表 PDF：从教务系统另存的课表 PDF，解析后先给你预览，确认无误再写入
· 课表截图：从相册选一张课表截图，识别后同样先预览再写入
如果导入的节次和当前作息对不上，会问你要不要一并把作息时间也导进来。

【看课表】
· 周视图一眼看完一周：今天高亮，单双周自动过滤，停课的周自动消失
· 左右滑动或点箭头翻周，一键回到本周
· 同一格撞车时两块并排显示并标出冲突，课程详情写明与哪门课重叠
· 课程详情里有教师、教室、周次、节次

【不止课程】
· 自定义安排：自习、实验、社团、健身都能占格子，支持周次范围
· 作息时间自己定：改节次、加一节、删一节自动重编号，还能从其他课表复制
· 多张课表：不同学期分开存，随时切换，可设主课表
· 学期设置：开学日与总周数填一次，之后每周都算得准

【关于隐私】
不联网、不申请权限、没有账号、没有统计上报。课表数据存在本机的数据库里，卸载即删除，也可以随时在应用内清空。
```

### 上架自检报过的 UX 问题（0.1.0 那次）

| 项 | 结果 | 怎么修的 |
|---|---|---|
| 字体：最小不得小于 8 fp | 不通过（2 次） | 钟点小字 7fp → 9fp（`CellLayout.GUTTER_TIME_FONT_SIZE`），窄格 8 → 9；加 `npm run check:ui` 静态守卫 + 2 条测试断言 |
| 转场：应淡入淡出、不应单帧直接切换 | 警告（7 次） | 新增 `view/Motion.ets`（透明度 300ms / `Curve.Friction`），挂到 16 个页面与弹层根节点 |
| 转场时长：8.5"≤200ms、8.5~12"≥250ms | 警告（6 次） | 同上，统一 300 ms（覆盖手机/平板/2in1 三档） |
| 滑动到边界应有反馈动效 | 警告（2 次） | 所有可滚动容器显式 `.edgeEffect(EdgeEffect.Spring)` |

细节与证据（含交叉淡化的实帧、字号实测 bounds）在
[`docs/ACCEPTANCE.md` §6.14](../docs/ACCEPTANCE.md)。**改完必须重新上传跑一次自检**才知道过没过。

### 审核信息怎么填

审核退回的第 1 条是「应用从教务系统表格导入课表功能需使用网页表格导致未完全遍历，无法测试」，
并建议提交账号。看完审核录屏（30 秒）后的真相是：**测试员手上就有 PDF，也选中了**，
是我们的解析链在真机上报错（见 `docs/ACCEPTANCE.md` §6.15），所以他走不完"导入"。
0.1.2 修的是解析链本身；**生产包里不放任何内置示例**（示例只留在 debug 包的开发者入口）。
因此审核信息只需要说清"不需要账号、直接用本地文件"：

- **测试账号 / 密码**：`无需登录（本应用没有账号，也不联网）`
- **测试说明**（可直接粘）：

```
本应用不需要账号，也不联网。导入用的是手机本地文件：
1) 课表导入：主页 → 导入 → 从 PDF 文件（选任意课表 PDF）→ 预览 → 合并到当前/导入为新课表；
   若学校给的是教务系统导出的 .xls/.html，走「从教务系统表格（.xls）」。
2) 作息导入：主页 → 作息 → 导入作息 → 从 PDF 文件 / 识别图片 / 粘贴文本 → 校对页 → 应用。
3) 没有文字层的扫描件 PDF 会自动把页面渲染成图再识别，结果会先放在预览/校对页供核对。
```

> 若还要求提供"可用的教务系统账号"：直接说明本应用**不登录任何教务系统**——导入是把学校导出
> 的 `.xls`/`.html`/`.pdf` 读进本机解析，不需要账号。

### 隐私声明表单怎么填（应用市场「我们如何收集和使用您的个人信息」）

本应用不收集任何个人信息，所以这一节只有第一条要勾：

- ✅ **1.1 我们为您提供了基本功能服务和全量功能服务…**
  - 「设置」保持默认
  - 「基本功能服务下」选 **不收集个人信息**
  - 「仅提供」填：`课表查看与编辑`
  - 「不提供」填：`账号登录、云端同步、消息推送`
- ⬜ 1.1 我们为您提供下述…（处理个人信息的那一条）—— **不勾**
- ⬜ 1.1 基于履行法定义务… —— **不勾**

### 隐私声明表单第 7 节：信息存储地点及期限

- **7.1** 选第二个选项「我们承诺，除法律法规另有规定外，我们对您的信息的保存期限应当为实现处理目的所必要的最短时间。」
  **不要**填「固定存储期限」—— 填了就等于承认服务器上长期留存。
- **7.2**「上述信息将会传输并保存至 `[____]` 的服务器」是必填项，而本应用**根本没有服务器**
  （不申请网络权限，数据只在本机）。填：`不涉及（本应用不向任何服务器传输或保存信息，数据仅保存在您的设备本地）`
  若表单提供「不涉及」之类的选项，优先选它。
