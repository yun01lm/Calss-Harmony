## 3. 应用介绍（限 8000 字，纯文本，不支持 HTML）

```
简课表是一款把课表装进手机的本地应用：打开就是周课表，不联网、不申请任何权限，数据只存在你自己的设备里。

【三种导入方式】
· 教务系统导出的 .xls：很多学校导出的其实是网页表格，直接选文件即可，课程名、教师、教室、周次、连堂节次都会自动拆好
· 课表 PDF：从教务系统另存的课表 PDF，解析后先给你预览，确认无误再写入
· 课表截图：从相册选一张课表截图，识别后同样先预览再写入
如果导入的节次和当前作息对不上，会问你要不要一并把作息时间也导进来。

【看课表】
· 周视图一眼看完一周：今天高亮，单双周自动过滤，停课的周自动消失
· 左右滑动或点箭头翻周，一键回到本周
· 同一格撞车时两块并排显示并标出冲突，课程详情写明与哪门课重叠
· 课程详情里有教师、教室、周次、节次

【不止课程】
· 自定义安排：自习、实验、社团、健身都能占格子，支持周次范围
· 作息时间自己定：改节次、加一节、删一节自动重编号，还能从其他课表复制
· 多张课表：不同学期分开存，随时切换，可设主课表
· 学期设置：开学日与总周数填一次，之后每周都算得准

【关于隐私】
不联网、不申请权限、没有账号、没有统计上报。课表数据存在本机的数据库里，卸载即删除，也可以随时在应用内清空。
```

## 4. 应用介绍截图（竖向，3~10 张）

应用市场的要求（2026-11-10 上传页原文）：**需上传 3~10 张；最低尺寸 1080×1920，宽高比 9:16；
PNG / JPG / JPEG（≤5 MB）或 WEBP（≤200 KB）**。所以成品统一是 **1080×1920 的 JPEG**：

| 文件 | 内容 |
|---|---|
| `screenshots/1-周课表.jpeg` | 满课的一周，今天（周二）高亮 |
| `screenshots/2-课程详情.jpeg` | 点色块看教师/教室/周次 |
| `screenshots/3-作息时间.jpeg` | 10 节作息，可改可加可导入 |
| `screenshots/4-导入课表.jpeg` | 三种导入通道 |

### 为什么是"裁"出来的

模拟器 Mate 90 Pro 的屏幕是 1280×2832（**9:19.9**，比 9:16 高），直接传比例不对。
`tools/make-store-shots.py` 按内容选一段 1280×2276（正好 9:16）的窗口再缩到 1080×1920：

| 截图 | 保留窗口（y 起..止） | 说明 |
|---|---|---|
| 1 周课表 | 136..2412 | 去掉状态栏，保留标题 + 第 1~8 节（晚间节次本来空着） |
| 2 课程详情 | 470..2746 | 详情卡在底部，只能切上面；从「本周 / 10 节」那行起，避开切断「第 1 周」 |
| 3 作息时间 | 136..2412 | 保留标题与 10 节作息 |
| 4 导入课表 | 470..2746 | 三通道按钮在底部弹层里，同上 |

原生截图留在 `screenshots/native/`（1280×2832），要重切就改 `WINDOWS` 再跑一次脚本。

### 数据从哪来（必须可复现，且不能是真实课表）

1. 模拟器 `Mate 90 Pro`（API 26），release 模式构建，用发布证书签一份装上去
2. 课表是**合成的**：`entry/src/main/resources/rawfile/demo-timetable.html`
   （12 门课、10 节作息，课程/教师/教室全是编的，不含任何真实姓名学号）
3. 导入入口在开发者面板：连点标题「简课表」5 次 →
   「用演示课表跑「导入 → 教务表格」（截图用）」→ 一并导入作息 → 覆盖当前课表
4. 关掉开发者面板，`hdc shell snapshot_display -f xxx.jpeg` 截图

> 截图里的界面与正式包完全一致；开发者面板只用来灌演示数据，没有入镜。

### 隐私声明表单怎么填（应用市场「我们如何收集和使用您的个人信息」）

本应用不收集任何个人信息，所以这一节只有第一条要勾：

- ✅ **1.1 我们为您提供了基本功能服务和全量功能服务…**
  - 「设置」保持默认
  - 「基本功能服务下」选 **不收集个人信息**
  - 「仅提供」填：`课表查看与编辑`
  - 「不提供」填：`账号登录、云端同步、消息推送`
- ⬜ 1.1 我们为您提供下述…（处理个人信息的那一条）—— **不勾**
- ⬜ 1.1 基于履行法定义务… —— **不勾**

### 隐私声明表单第 7 节：信息存储地点及期限

- **7.1** 选第二个选项「我们承诺，除法律法规另有规定外，我们对您的信息的保存期限应当为实现处理目的所必要的最短时间。」
  **不要**填「固定存储期限」—— 填了就等于承认服务器上长期留存。
- **7.2**「上述信息将会传输并保存至 `[____]` 的服务器」是必填项，而本应用**根本没有服务器**
  （不申请网络权限，数据只在本机）。填：`不涉及（本应用不向任何服务器传输或保存信息，数据仅保存在您的设备本地）`
  若表单提供「不涉及」之类的选项，优先选它。
